ABOUT THE PROJECT

About TCG Meta

Learn more about the purpose and design of this website.

01

What is this website?

One Piece TCG Meta is a student web development project designed to organize information about the One Piece Card Game.

The goal is to create a simple and visually appealing way to explore decks, leaders, and meta information.

02

What can you find?

  • Home
    Quick overview of the current meta.
  • Decks
    Deck usage and searchable deck lists.
  • Leaders
    Leader tier list information.
  • About
    Information about the project.
03

Accessibility

Accessibility was considered throughout the design of the website.

  • Semantic HTML
  • Keyboard-friendly navigation
  • Visible focus indicators
  • Skip-to-content link
  • Labeled form controls
  • Responsive design
04

Technology

This website was created using the fundamental web technologies covered throughout the course.
